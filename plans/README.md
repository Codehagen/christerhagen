## Findings considered and rejected

- **base-ui bloats First Load JS** — rejected. Verified the two always-loaded root
  chunks contain zero base-ui tokens; `Button` is imported in `components/ui/button.tsx`
  but never rendered (only the `buttonVariants` cva is used) so it tree-shakes out,
  and `Badge` renders as a server component. Nothing to fix.
- **Add `priority` to the home portrait** — rejected. The portrait sits *below* the
  hero text in `components/home-content.tsx`; the LCP element is the `<h1>` (text),
  not the image. `priority` would mis-prioritize the preload budget.
- **Raw `<img>` in `components/brand-content.tsx`** — rejected as a perf item. It
  renders `public/favicon.svg` (329 bytes inline SVG); `next/image` gives no benefit
  for a tiny SVG.
- **Custom cache headers** — rejected. Vercel already serves `/_next/static`
  immutable; nothing to add.
